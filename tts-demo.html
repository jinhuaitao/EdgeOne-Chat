用三句话解释一下 Cloudflare Worker 是什么。

Cloudflare Workers 是一种运行在边缘节点上的无服务器运行时。

你把一段 JavaScript 上传到 Cloudflare，它会在全球数百个机房就近执行，用户请求不必绕回源站。

典型用途是改请求、做鉴权、当 API 网关，或者在几毫秒内返回一个页面。

那它和传统服务器比，代码里长什么样？给个例子。

就是一个默认导出对象里的 fetch 方法，例如：

js示例
export default {
  async fetch(request, env) {
    return new Response('Hello World');
  }
};
